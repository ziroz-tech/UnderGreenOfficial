WORLD // ARCHIVE 01

緑を育てることが、罪になった世界。

核戦争で地表が汚染され、人々は食料生産企業が管理する地下シェルターへ逃げ延びた。土も種も知識も、企業の所有物だ。

失われた栽培知識を手にしたあなたは、ホコリと鉄サビにまみれた一室で、禁じられた水耕栽培を始める。

GAME SYSTEM // LIVE BUILD

ディストピア違法農場経営シュミレーション

荒廃した地下世界で禁じられた植物を育て、設備・売り先・労働を選ぶ。小さなレタス1株から、地下社会へ影響を広げる違法農場経営が始まります。

  1. FEATURE 01触って育てる立体農場

    種を運び、手入れし、成長を待って収穫する。作物ごとの環境条件と水・養液、設備の汚れまでが生産に影響します。

  2. FEATURE 02地下空間を生産拠点へ

    栽培PODや大型BOX、製水器、養液培養槽などを配置。区画を買い足し、自給できる農場へ拡張します。

  3. FEATURE 03売り先が農場の意味を変える

    下層市場、医療区画、上層市場、反体制派では求める作物も価格も異なります。需要と関係性を読み、誰へ食料を渡すか選びます。

  4. FEATURE 04停電で摘発をやり過ごす

    管理局の接近中は拠点の電源を落として農場を隠せます。しかし光も生産設備も止まるため、安全と稼働を天秤にかけます。

  5. FEATURE 05労働を組みロボットへ渡す

    植え付け・収穫・清掃・物流をノードで接続し、業務フローを設計。技能と性格の異なるサポートロボットへ仕事を割り当てます。

  6. FEATURE 06経営の結果が物語になる

    どの市場を支え、何を育て、どこまで危険を冒すか。日々の経営判断が人物との関係と複数の結末へつながります。
